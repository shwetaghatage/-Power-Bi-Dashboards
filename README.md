# -Power-Bi-Dashboards
Superstore Sales & Profit Analysis Dashboard

Project Overview

Developed an interactive sales dashboard using Microsoft Power BI and the Sample Superstore dataset to analyze business performance.

Key Features

- KPI cards for total sales, profit, and quantity
- Sales analysis by customer segment
- Quantity analysis by product category and shipping mode
- Year-wise profit trend analysis
- Region-based filtering

Tools Used

- Microsoft Power BI
- Data Visualization
- Business Data Analysis

Objective

To identify sales trends, understand profitability, and support data-driven business decisions.
